# JevBench v1.4.0

Fresh sealed decisions, a stronger generalization check, and a score tuned to Jev-class systems.

## Top five

1. Jev 1.13.0 (TypeSafe AI) — 63.29
2. JevK5 v0.2.0 — 62.04
3. Hopper — 59.43
4. Winnow-12B Q8 — 55.58
5. reflex 4B — 53.99

The v1.4 release adds 308 sealed decisions at 20% of Intelligence, blends Calibration toward the sealed-inclusive measurement, reduces Intelligence when the public-to-sealed accuracy gap exceeds 25 points, and combines the four axes with a harmonic mean. Speed and Cost each receive a separate gate below 50. Their underlying measurements are unchanged.

The [method](METHOD-v1.4.md) states the exact formula and caveats. The [aggregate result artifact](../results/v1.4/jevbench-v1.4-results.json) includes all 76 listed systems and API exposure flags. The sealed tasks and answers are not published. swanOne is listed without a v1.4 rank because its sealed run was not completed.

The interactive ranking is at https://benchmarkheaven.com/jev-models.
