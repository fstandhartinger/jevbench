# ImageJevBench Box track — public set v0.1 (14 Oct 2026)

300 items for the Box question type (find one described thing in an image, answer with a bounding box + confidence).
`items.jsonl`: one item per line — `instructions` (the image is called `photo`), `gold` box as fractions of width/height
(`left`, `top`, `right`, `bottom`), image size, `family` (coco / doc / ui), `kind` (single, ref, small, doc, ui), `size_bucket`,
`sha256` of the image file, licence, attribution and provenance. Images are in `images/` (COCO JPEGs unchanged; rendered PNGs).

Method and scoring: METHOD.md. Results: https://benchmarkheaven.com/image-jev-bench#box-track
A separate sealed set (600 items) is held back for official runs and is not published.
